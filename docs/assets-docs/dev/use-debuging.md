# 디버깅

:::info 내용
- Frontend React 개발자는 화면 디버깅 도구(예: React Developer Tools, 브라우저 콘솔 등)를 활용하여 렌더링 결과와 상태 변화를 확인할 수 있습니다.
- 디버깅 시 자주 사용하는 기능으로는 React 컴포넌트 트리 확인, props 및 state 실시간 확인, 네트워크 요청 추적, 콘솔 로그 출력 등이 있습니다.
- 개발자 도구에서 "소스(Source)" 탭을 이용해 코드에 직접 브레이크포인트를 설정하여, 실행 흐름을 단계별로 추적할 수 있습니다.
- Redux를 사용하는 경우, Redux DevTools를 통해 Action, State 변화 과정을 한눈에 파악할 수 있습니다.
- 문제 발생 시, 에러 메시지와 스택트레이스를 주의 깊게 보고, 필요한 경우 콘솔에 정보를 출력해서 원인 파악에 도움을 받을 수 있습니다.
- 디버깅 과정에서 문제가 재현되는 최소한의 코드를 만드는 것도 원인 파악에 도움이 됩니다.
:::

## 기본 디버깅 방법

1. **React Developer Tools 설치**
   - 크롬/파이어폭스 확장 프로그램 React Developer Tools를 설치합니다.
   - 컴포넌트 트리, props/state, hooks 정보를 쉽게 확인할 수 있습니다.

2. **브라우저 개발자 도구 활용**
   - 콘솔(Console) 탭에 `console.log()`를 활용하여 변수 값이나 흐름을 추적합니다.
   - Network 탭으로 API 요청 및 응답 정보를 확인할 수 있습니다.
   - 요소(Elements) 탭에서 DOM 구조와 스타일을 점검할 수 있습니다.

3. **코드 브레이크포인트 사용**
   - Source(소스) 탭에서 코드의 특정 지점에 브레이크포인트를 걸고, 변수 값과 실행 흐름을 단계별로 분석합니다.

4. **Redux DevTools 사용(선택적)**
   - Redux를 사용할 경우, Redux DevTools를 설치해 State 변화 및 Action Dispatch 내역을 시각적으로 확인합니다.

5. **에러 로그 분석**
   - 에러 메시지와 스택 트레이스를 통해 문제의 위치와 원인을 파악합니다.
   - 상황에 따라 로그 레벨(`log`, `warn`, `error`)을 구분하여 출력합니다.

6. **문제 재현 최소화**
   - 복잡한 문제는 최소 재현 코드를 따로 만들어 단계적으로 문제를 좁혀가는 것이 효과적입니다.
